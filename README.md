# A12IHSSN LOCATION VOITURE

Site vitrine responsive en HTML, CSS et JavaScript, sans installation ni compilation.

Ouvrez `index.html` dans votre navigateur. Pour utiliser un serveur local : `python -m http.server 8000`, puis ouvrez http://localhost:8000.

- `index.html` : accueil, catalogue, filtres, recherche et préparation de demande.
- `privacy-policy.html` : politique de confidentialité séparée.
- `style.css` : styles et mise en page mobile.
- `script.js` : catalogue et interactions.

Les six modèles, leurs tarifs et les photos sont des exemples. Les photographies ne représentent pas nécessairement les modèles indiqués. Remplacez les entrées `cars` dans `script.js` avec la flotte réelle avant publication. Les images Unsplash et les polices Google nécessitent Internet.

Le formulaire calcule un montant indicatif par période de 24 heures et prépare un texte à copier. Il n’envoie aucune réservation. Ajoutez les coordonnées réelles de l’agence pour permettre les demandes à distance. Aucun numéro, email ou témoignage n’a été inventé.

Avant publication, renseignez l’hébergeur et ses pratiques dans la politique de confidentialité, vérifiez les tarifs et conditions de location, et adaptez les informations aux traitements réellement mis en place.
